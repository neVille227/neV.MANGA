# neV.MANGA — Portail

Portail éditorial et espace de consultation du studio neV.MANGA.

## Fonctionnalités de cette version
- Accueil et catalogue filtrable des œuvres.
- Fiche de présentation de PROJECT: BEYOND.
- Fiches consultables des sept personnages principaux.
- Présentation des cinq États de Néréth.
- Vue de l’architecture narrative et règles de continuité.
- Recherche transversale dans les données intégrées.
- Espace de brouillons local au navigateur.
- Interface responsive et navigation mobile.

## Architecture
- `index.html` : structure du portail.
- `styles.css` : identité graphique et responsive design.
- `app.js` : navigation, recherche, fiches et brouillons locaux.
- `content.js` : données éditoriales structurées de PROJECT: BEYOND.

## Lancer en local
Ouvrir `index.html` dans un navigateur moderne ou servir le dossier avec un serveur statique.

## Limites explicites
Le portail actuel est un site statique. Les brouillons de l’espace Studio sont conservés uniquement dans le stockage local du navigateur : ils ne sont ni sécurisés comme un espace administrateur, ni synchronisés entre appareils. Les comptes, rôles, base de données, téléversement partagé, publication de chapitres et administration multi-utilisateur nécessitent un backend et une authentification sécurisée à configurer séparément.

Les portraits et planches ne sont pas remplacés par des images inventées. Les fiches affichent des emplacements en attente des illustrations originales validées.
