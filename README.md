# neV.MANGA

Première interface du portail neV.MANGA.

## Stack
- HTML sémantique
- CSS responsive, sans framework
- JavaScript natif
- Déploiement statique Render

## Lancer en local
Ouvrir `index.html` dans un navigateur ou lancer un serveur statique depuis la racine du dépôt.

## Sections
- Accueil éditorial
- Présentation de neV.MANGA
- Catalogue des œuvres
- Mise en avant de PROJECT: BEYOND
- Entrées univers : personnages, world-building, chronologie, galerie
- Présentation de l’atelier de création

## État
Version initiale de présentation. Les espaces éditoriaux sont en place ; les fiches détaillées, les galeries réelles, les comptes et les outils d’administration restent à connecter aux contenus et services correspondants.
